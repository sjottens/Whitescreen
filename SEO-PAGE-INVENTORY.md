- Transactional: Test tools, contact form

**Content Quality**:
- High: Original, detailed, specific, well-structured
- Medium: Adequate, some generic language, missing depth
- Low: Thin, generic, minimal value

**Search Intent Match**:
- Yes: Page clearly answers user's likely search query
- Partial: Page partially addresses intent
- No: Page doesn't match search intent

**Action**:
- KEEP: Page is solid, minimal changes
- IMPROVE: Page exists but needs enhancements
- MERGE: Should combine with another page
- REDIRECT: Outdated, duplicate, or misaligned
- REMOVE: No value, low traffic potential
- CREATE: Recommended new page (if not exists)
